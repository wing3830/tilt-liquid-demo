# スマホの傾きで揺れる液体

スマホを傾けると、丸いグラスの中の液体が揺れるデモ。傾きセンサー（DeviceOrientation）を使う単一HTML。

> 作者談：マジで何に使うか分からんけど上げとく。

## 使い方
- 公開版はこちら：https://wing3830.github.io/tilt-liquid-demo/
- スマホで開いて「センサーを許可して開始」を押すと、傾きに合わせて液体が動く
- iOS 13以降のセンサー許可リクエストに対応。センサー取得にはHTTPS環境が必要（PagesはHTTPSなのでOK）

## 技術
- HTML 1ファイルで完結（約4KB、全125行）。外部ライブラリ・APIなし
- 液面の傾きは gamma（左右の傾き）をそのまま回転に、高さは (beta − 90) × 2 で計算
- 元は Gist に非公開で置いていた `gistfile1.htm`。このリポジトリでは `index.html` として収録（内容は同一）

## 既知の制限（検討メモ）
- 液量に上限・下限（clamp）がないため、大きく傾けると液体が消えたり溢れたりする
- beta=90（スマホを垂直に持つ）前提の計算で、横画面や寝かせた姿勢には未対応
- センサーイベントごとに transition がかかるため、速い傾けでは液面が遅れて追従する
